Features:

- Adds products to picking using barcode scanner
- todo: Adds products to inventory by scanning product barcode or lot
  barcode.

It also works if the printed bar code is represented by a concatenation
between the product code and the batch code using one of the separators:
'-', '/'. ' '. In order to scan the bar codes with lot in piking it is
necessary that the operation type to have the option "Show detail
operation" active.
